# 归类速查词典

- 适用范围：个人账本日常收支的科目归类。
- 读取方式：按需检索（`python3 scripts/ledger.py lookup <关键词>`），不必通读。
- 维护：本词典未收录的物品或商家，按 `rules/classification.md` 第 2 节归类后补入对应表格。

检索顺序：先按物品（第 1 节）匹配，未命中时再按商家或平台（第 2 节）匹配；二者冲突时以物品为准，例如在京东购药计入医疗，不计入购物。词典覆盖国家统计局八大类、COICOP 十三大类与主流记账 App 默认分类下的常见支出。表内科目省略 `Expenses:` 前缀。

## 3 非消费业务

下列业务不得直接记为费用。

| 用户表述 | 处理 |
|---|---|
| 借给 XX / XX 借我 | 挂 `Assets:Receivable:<对方>` / `Liabilities:Payable:<对方>`（对象少时用 `Other`）；摘要「其他应收款-借给<对方>」/「借款-向<对方>借入」，归还时「收回<对方>借款」/「偿还<对方>借款」 |
| 帮 XX 垫付、替单位先付待报销 | 挂应收往来，摘要「其他应收款-代垫<对方><事项>」；报销到账时冲回，摘要「收回<对方><事项>」 |
| 还花呗/白条/信用卡 | 借负债、贷付款账户；摘要「偿还花呗」「偿还京东白条」「偿还招行信用卡」 |
| 余额宝/零钱通/银行卡之间转、提现、充值 | 资产内部划转，不进收支；对方写转出机构，摘要「银行转账-<转出>转<转入>」；取现存现写「银行取现」「银行存现」 |
| 买基金、股票、定投 | 记投资资产（`Assets:Invest:Fund` / `Stock`），摘要「申购基金」「指数基金定投」「买入股票」；赚亏记 `Income:Invest:PnL`，摘要「投资收益-…」 |
| 退款、AA 收回 | 冲原消费科目（负数），摘要末尾加「退款」，如「餐饮-火锅分摊退款」，不记收入 |
| 银行利息、理财利息 | `Income:Invest:Interest`「利息收入-活期存款利息」 |
| 银行余额比账上多 / 少 | 先查漏记；查不出的经用户确认后，多：`Income:Other`「其他收入-对账差额」；少：`Finance:Fee`「财务费用-对账差额」，不用负数费用冲。见 `rules/reconciliation.md` |
| 丢钱、被骗、借出去收不回、赔给别人 | `Expenses:Other`「其他-现金丢失」「其他-坏账损失」「其他-赔偿」，`note:` 写清经过；借款收不回先冲掉对应的 `Receivable` |
| 可退押金 | 记 `Assets:Receivable:Other`，摘要「其他应收款-<事项>押金」；退回时「收回<事项>押金」；不可退部分才记费用 |
| 定金、预付的服务费 | 记 `Assets:Prepaid:Deposit`，摘要「预付款项-<事项>定金」；服务完成后转入对应费用 |
| 社保/医保/公积金个人账户入账 | `Income:Benefit:*` 分列，摘要「社保入账-医疗保险」「社保入账-养老保险」「社保入账-住房公积金」 |
| 发工资、加班费、补贴 | `Income:Salary`「工资收入-10月工资」；对方写「任职单位」或单位简称 |
| 奖金、年终奖、绩效 | `Income:Bonus`「奖金收入-年终奖」；账本未设该科目时记 `Income:Salary`「工资收入-年终奖」 |
| 收到红包、礼金、压岁钱、家人给的生活费 | `Income:Redpacket`「红包收入-生日红包」 |
| 兼职、外快、接私活（软件外包、稿费、讲课费） | `Income:Labor`「劳务收入-软件外包」；用户未说明具体劳务的写「劳务收入-劳务费」 |
| 卖掉自用的闲置物品 | `Income:Other`「其他收入-出售闲置<物品>」；以转卖为业、有进货成本的按副业记 |
| 返现、余额奖励、中奖 | `Income:Other`「其他收入-<事项>」 |
| 基金现金分红 / 卖基金赚了亏了 | `Income:Invest:Dividend`「投资收益-<标的>现金分红」/ `Income:Invest:PnL`「投资收益-赎回<标的>」 |
| 代购、代充会员、摆摊这类小生意收的钱 | `Income:SideBiz`「副业收入-代充会员」，对方写「客户」；进货款记 `Expenses:SideBiz`「副业成本-代充会员进价」 |
| 来源说不清的进账 | `Income:Other`「其他收入-未注明来源进账」，对方「未注明来源」，不追问 |
