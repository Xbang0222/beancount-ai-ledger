# 估值与净资产（专题）

- 适用范围：外币、加密货币、金银、基金、股票的折算，以及净资产的口径。
- 读取时机：计算总资产或净资产、查询价格、向用户报告资产或储蓄率。

## 1 折算口径

- 可变现的资产在计算总资产、净资产时一律按当日价格折算为本位币。
- 价格即取即用，不写入账本：`networth` 默认联网取价。回报时写明所用价格、数据时间与来源，`networth` 的输出已包含这些信息。
- 无法取得当日价格时，`networth` 给出提示并改用账内最近一次的 `price`，同时标注「非当日价格」。不得以旧价格或记忆中的数字充当当日价格。
- 用户提供当日报价时，以 `--rate 代码=价格` 传入，可重复传入多个；`--offline` 只使用账内价格。

## 2 价格查询

```bash
python3 scripts/ledger.py quote USD USDT AU F161226 SH600519
python3 scripts/ledger.py quote AU --date 2026-02-11
```

代码的写法同时是账本中 commodity 的写法：

| 资产 | 代码 | 数据来源 |
|---|---|---|
| 外币、加密货币 | ISO 代码：`USD`、`HKD`、`USDT`、`BTC` | fawazahmed0/exchange-api，每日更新，可查历史 |
| 黄金、白银（每克） | `AU`、`AG` | 同上，按盎司价换算为克 |
| 场外基金 | `F` + 6 位代码：`F161226` | 天天基金单位净值，可查历史 |
| A 股、港股、美股 | `SH600519`、`SZ000001`、`BJ430047`、`HK00700`、`US.AAPL` | 腾讯行情最新价，港股、美股再按汇率折算 |

## 3 基金、股票与理财产品

- 已知份额并按「份额 代码 {单位成本}」登记的，`networth` 自动按现价折算。
- 按金额登记并逐日登记收益的，账面金额即市值，不再折算。
- 无法联网取价的标的（理财产品、非公开基金等）以 `price` 指令登记在 `common/prices.beancount`：

  ```
  YYYY-MM-DD price <代码> <净值> <本位币>   ; <来源>
  ```

## 4 受限资产与不计入净资产的余额

- 受限资产指归本人所有、但在约定条件成就前不能支取的资产，如养老保险个人账户、医保个人账户。在其 `open` 指令下写 `restricted: TRUE`；`networth` 将其单列于「受限资产」，计入总资产与净资产，并在折合本位币后列示「其中：受限资产」与「可动用净资产」（净资产扣除受限资产）。
- 报告净资产时同时报告净资产与可动用净资产；可动用净资产反映可支配的财务状况，净资产反映全部权益。
- 住房公积金可按规定提取，计入资产，不标注 `restricted`。
- 不属于本人或不应计入净资产的余额，在其 `open` 指令下写 `networth: FALSE`；`networth` 将其单列于「不计入净资产」，不计入任何合计。旧版账本中养老保险、医保个人账户标注 `networth: FALSE` 的，改为 `restricted: TRUE`。
- 报告储蓄率时，`Income:Benefit:Pension`、`Income:Benefit:Medical` 不属于可支配收入，须单独说明。

## 5 向用户报告资产

- 用户询问资产或余额，且多本账均归其一人所有时，采用合并口径，使用 `networth` 的输出。
- 只列示实际资金（银行卡、微信、支付宝、现金、基金等）和对外的债权债务（信用卡、花呗、他人欠款等）。
- 账本之间的往来科目在合并后相互抵销，不列示；用户询问或对账需要时再单独说明。
