# 豆包 + 私有仓库：云电脑 AI 记账，自动存到 GitHub

适合用豆包这类自带云电脑的 AI 记账的人。比[不用 Git](NO-GIT.md) 的做法多一次登录，之后的好处是：

- **每记一笔就自动存到你的 GitHub 私有仓库**，不用每天往云盘存备份，也不会出现"最多补一天"。
- 哪天记了什么、改过什么，在 GitHub 网页上就能看。
- 换 AI 工具、换到电脑上用、几个人一起记，都从同一个仓库拉，不用传压缩包。

**你只需要有一个 GitHub 账号，再输一次验证码。** 建仓库、下载、上传都是豆包的事，不用敲命令，也不用进 GitHub 的设置页。

## 第一次：复制这段话发给豆包

还没有 GitHub 账号的，先去 <https://github.com> 用邮箱注册一个，然后整段发出去：

```text
我想用这个开源项目记账：https://github.com/Xbang0222/beancount-ai-ledger
账本要存到我自己的 GitHub 私有仓库，每记一笔自动上传。

请你在云电脑里完成下面的事，命令都由你来做：
1. 先读这个项目 AGENTS.md 里的「云电脑连私有仓库」一节，照着做。
2. 需要我登录 GitHub 时，把网址和验证码发给我，我去输入。
3. 帮我建一个私有仓库，放到个人目录下的固定位置 ~/AI记账/ledger，试一次上传，成功了告诉我。
4. 然后读里面的 AGENTS.md 和 CATEGORIES.md，帮我建账。需要哪些信息请一条一条问我。
```

## 豆包让你登录时

豆包会发来一个网址（`https://github.com/login/device`）和一个 8 位验证码，形如 `ABCD-1234`：

1. 用手机或电脑打开那个网址，登录你的 GitHub 账号。
2. 输入验证码，点 **Continue**，再点绿色的 **Authorize**（授权）。
3. 回去告诉豆包「好了」。

验证码十几分钟内有效，过期了让豆包重新给一个。之后它会建好仓库，像[不用 Git](NO-GIT.md) 那样问你有哪些账户、各有多少钱，带你记第一笔。

## 以后每次：开头加这一句

```text
帮我记账，账本在云电脑的 ~/AI记账/ledger，按里面的 AGENTS.md 来。
今天：午饭 18 微信，打车 32 花呗。
```

每记完一笔，豆包会自动上传到你的仓库。

## 安全吗

- 仓库是**私有**的，只有你自己能看。豆包建好后会核对一遍。
- 授权后，豆包的云电脑能访问你 GitHub 账号下的仓库。这个账号只用来记账的话没什么顾虑；账号里还有别的重要仓库的，用下面「只给一个仓库的钥匙」的做法更稳妥。
- 不想让豆包再碰了：GitHub 右上角头像 → Settings → Applications → Authorized OAuth Apps，找到 GitHub CLI 点 Revoke，立刻失效。

## 别人帮你配好的情况

家人或朋友已经替你建好了私有仓库和账本，可以给这个仓库单独配一把**只能开这一个仓库的钥匙**，把整段配置话术连同钥匙发给你。你什么都不用懂，原样转给豆包就行。

帮人配的那一方按 `AGENTS.md`「云电脑连私有仓库」里「只给一个仓库的钥匙」一段做。

## 上传不上去怎么办

- 豆包说"连不上 GitHub"：多半是云电脑的网络连不到 GitHub。让它「请实际检查后回答，不要猜」。确实连不上的，改用[不用 Git](NO-GIT.md) 的云盘备份做法，账本照样能记。
- 豆包说"没有权限""登录失效"：让它重新发一次网址和验证码，再授权一次。
