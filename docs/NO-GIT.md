# 不用 Git：账本存云盘

适合只用豆包这类 AI 的人：它自带一台云电脑和一个云盘。你不需要 GitHub 账号，不用装软件，也不用敲命令。

云电脑每次会重置，里面的文件留不住，所以账本存在你自己的云盘里，是一个压缩包。

## 第一次：复制这段话发给豆包

不用下载任何东西，也不用改一个字，整段复制发出去：

```text
我想用这个开源项目记账：https://github.com/Xbang0222/beancount-ai-ledger

请你在云电脑里完成下面的事：
1. 下载并解压这个项目：https://github.com/Xbang0222/beancount-ai-ledger/archive/refs/heads/main.zip
2. 先读里面的 AGENTS.md（重点看「不用 Git 时」一节）和 CATEGORIES.md，之后严格按里面的规矩来。
3. 帮我建账，从今天开始记。我不知道要准备什么，需要哪些信息请一条一条问我。
4. 我不会用 Git。账本请存到我云盘的「AI记账」文件夹，每次记完都存一次，并告诉我存好了。
```

接下来豆包会问你几个问题，照实回答就行：

- 你有哪些账户：银行卡、微信、支付宝、现金；有没有花呗、信用卡这类欠款。
- 每个账户现在有多少钱。打开 App 看一眼，照着报数字。
- 平时没说怎么付的，默认算哪个账户。

问完它会建好账本，存进你的云盘，带你试记第一笔，再告诉你以后每次怎么开始。全程你只需要回答问题。

已经清楚自己有哪些账户的，可以在那段话后面直接补一句，省掉来回问答：

```text
我有：招商银行卡 5000，支付宝 1200，微信 800；花呗欠 420。平时没说怎么付的就算微信。
```

## 以后每次：开头加这一句

每次新开一个对话，先发这句，后面跟上要记的账：

```text
帮我记账。账本在我云盘的「AI记账」文件夹，取最新的 ledger-backup 压缩包，按里面的 AGENTS.md 来。
今天：午饭 18 微信，打车 32 花呗。
```

同一个对话里接着记，就不用再说第一句，直接说「晚饭 45 支付宝」。

记账、改错、查账怎么说，见[使用指南](GUIDE.md)。

## 你会看到的两件事

- 开始时 AI 先报一句「账本里最后一笔是 10 月 3 日买菜 35 元」。跟你记得的对不上，就说「不对，这是旧的」，让它找最新的那份。
- 记完后 AI 说「已存到云盘」。没说就问一句「存到云盘了吗？」。

## 账本在云盘里长什么样

「AI记账」文件夹里是几个 `ledger-backup-日期-时间.zip`。日期最新的就是当前账本，旧的是历史版本。AI 只留最近 5 份，更早的会自动删掉，想多留就跟它说。

占不了多少地方：一份压缩包一百多 KB，记满一年也就几百 KB，5 份加起来不到一张照片大。

## 觉得慢或者麻烦

- **每次新对话开头会慢一点。** 云电脑重置后要重新装一次记账工具，通常几十秒。同一个对话里接着记就不用再等，所以一天的账尽量在一个对话里记完。
- **不用每笔都等它存。** 一口气说好几笔，AI 会记完这一批再存一次。
- **开场白懒得每次打。** 把「以后每次」那句存进手机的备忘录或输入法的常用语，用的时候粘贴。

想换一个 AI 工具，或者换到电脑上用，把最新的压缩包带过去解压即可。

## 它是怎么保证不丢账的

- AI 每次改动后运行 `ledger.py backup`，把整个账套打成压缩包存回云盘。
- 账本有错误时 `backup` 不生成压缩包，不会拿坏的盖掉好的。
- 云盘里找不到账本时，AI 会先问你，不会自己新建一本。

给 AI 的完整规矩写在 [`AGENTS.md`](../AGENTS.md)「不用 Git 时」一节。
