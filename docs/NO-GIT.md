# 不用 Git：只用豆包记账

适合只用豆包这类 AI 的人：它自带一台云电脑和一个云盘。你不需要 GitHub 账号，不用装软件，也不用敲命令。

账本就放在豆包的云电脑里，每次对话直接接着记。另外每天往你的云盘存一份备份，当保险。

## 第一次：复制这段话发给豆包

不用下载任何东西，也不用改一个字，整段复制发出去：

```text
我想用这个开源项目记账：https://github.com/Xbang0222/beancount-ai-ledger

请你在云电脑里完成下面的事：
1. 把这个项目放到个人目录下的固定位置 ~/AI记账/ledger，不要放在这次对话的工作目录里。
2. 先读里面的 AGENTS.md（重点看「没有远程仓库时」一节）和 CATEGORIES.md，之后严格按里面的规矩来。
3. 帮我建账，从今天开始记。我不知道要准备什么，需要哪些信息请一条一条问我。
4. 我不会用 Git 和 GitHub。每天往我云盘的「AI记账」文件夹存一份备份，存了告诉我。
```

接下来豆包会问你几个问题，照实回答就行：

- 你有哪些账户：银行卡、微信、支付宝、现金；有没有花呗、信用卡这类欠款。
- 每个账户现在有多少钱。打开 App 看一眼，照着报数字。
- 平时没说怎么付的，默认算哪个账户。

问完它会建好账本，带你试记第一笔，再告诉你以后每次怎么开始。全程你只需要回答问题。中途它要你授权访问云盘，点同意。

已经清楚自己有哪些账户的，可以在那段话后面直接补一句，省掉来回问答：

```text
我有：招商银行卡 5000，支付宝 1200，微信 800；花呗欠 420。平时没说怎么付的就算微信。
```

## 以后每次：开头加这一句

每次新开一个对话，先发这句，后面跟上要记的账：

```text
帮我记账，账本在云电脑的 ~/AI记账/ledger，按里面的 AGENTS.md 来。
今天：午饭 18 微信，打车 32 花呗。
```

同一个对话里接着记，就不用再说第一句，直接说「晚饭 45 支付宝」。不用每天记，攒几天一起说也行，说清楚哪天花的就可以。

把这句存进手机备忘录或输入法的常用语，用的时候粘贴。

记账、改错、查账怎么说，见[使用指南](GUIDE.md)。

## 你会看到的三件事

- **开始时 AI 先报一句**「账本里最后一笔是 10 月 3 日买菜 35 元」。跟你记得的对不上，就告诉它。
- **每天第一次记完，AI 会说**「今天的备份已存到云盘」。同一天后面再记，不会重复存。想马上存一份，说「存一下云盘」。
- **偶尔 AI 会说**「需要重新授权云盘」。点一下同意就行，账本不受影响。

## 账本在哪，会不会丢

- **平时用的那份**在豆包云电脑里你的个人目录下。云电脑会重启，但个人目录里的东西不会被清掉，换对话也还在。
- **保险的那份**在你云盘的「AI记账」文件夹，是一个 `ledger-backup-日期-时间.zip`，AI 存好新的才删旧的。几百 KB，比一张照片小。**别删这个文件夹。**
- 这份备份里带着完整的改动记录：哪天记了什么、哪一笔改过、改之前是什么样，都能让 AI 查出来。所以只留一份就够。
- 万一云电脑里那份找不到了，AI 会从云盘最新的备份恢复，并告诉你恢复的是哪天的。那天之后记的账需要补，所以最多补一天。
- 账本有错误时不会生成备份，不会拿坏的盖掉好的。

想换一个 AI 工具，或者换到电脑上用，让豆包「存一下云盘」，把最新的压缩包带过去解压即可。

## 项目更新了怎么升级

发一句：

```text
帮我升级记账项目，账本数据不要动。升级完告诉我升到了哪个版本、最后一笔是什么。
```

## 之前用的是"每次从云盘取压缩包"的旧做法

发这段，让豆包把账本搬到固定位置，之后就按上面的新做法来：

```text
记账项目换了做法，请帮我搬一次家，账本数据不能动：
1. 从我云盘「AI记账」文件夹取最新的 ledger-backup 压缩包，解压到 ~/AI记账/，得到 ~/AI记账/ledger。
2. 下载新版项目：https://github.com/Xbang0222/beancount-ai-ledger/archive/refs/heads/main.zip
   用新版覆盖账本里的 scripts、tests、docs 三个文件夹和 AGENTS.md、requirements.txt、requirements-dev.txt、pyproject.toml。
   其他的不要动，特别是 personal 文件夹、ledger.toml、CATEGORIES.md、STATE.md。
3. 重读新的 AGENTS.md「没有远程仓库时」一节，按里面的规矩自检、提交。
4. 告诉我最后一笔是什么，然后存一份新的备份到云盘。
以后账本就常驻 ~/AI记账/ledger，每天往云盘备份一次。
```

## 出问题时怎么问豆包

它卡住、说连不上、或者说的话你拿不准时，加一句「请实际检查后回答，不要猜」。它会老实说哪些是查过的、哪些是推断的。

给 AI 的完整规矩写在 [`AGENTS.md`](../AGENTS.md)「没有远程仓库时」一节。
