# 不使用 Git：通过豆包记账

- 适用对象：只使用豆包这类自带云电脑与云盘的 AI 的用户。无需 GitHub 账号，无需安装软件，无需执行命令。
- 存放方式：账本常驻豆包云电脑的个人目录，每次对话接续记账；每日向用户的云盘备份一份。
- AI 一侧的作业要求见 [`AGENTS.md`](../AGENTS.md)「没有远程仓库时」与 [`docs/AI-SETUP.md`](AI-SETUP.md) 同名一节。

## 1 首次使用

无需下载任何文件，将下列内容原样发送给豆包：

```text
我想用这个开源项目记账：https://github.com/Xbang0222/beancount-ai-ledger

请你在云电脑里完成下面的事：
1. 把这个项目放到个人目录下的固定位置 ~/AI记账/ledger，不要放在这次对话的工作目录里。
2. 先读里面的 AGENTS.md、docs/AI-SETUP.md（重点看「没有远程仓库时」一节）和 rules/daily.md，之后严格按其中的规定执行。
3. 帮我建账，从今天开始记。我不知道要准备什么，需要哪些信息请一条一条问我。
4. 我不会用 Git 和 GitHub。每天往我云盘的「AI记账」文件夹存一份备份，存了告诉我。
```

豆包随后询问以下信息，如实回答即可：

| 问题 | 回答方式 |
|---|---|
| 有哪些账户 | 银行卡、微信、支付宝、现金；花呗、信用卡等欠款 |
| 各账户的余额 | 打开 App 查看后报出数字 |
| 默认付款账户 | 未说明付款方式时记入哪个账户 |

询问结束后，豆包建立账本、引导试记第一笔，并说明此后每次的开头语。过程中要求授权访问云盘时，选择同意。

已清楚账户情况的，可在上述内容之后补充一句，省去逐项询问：

```text
我有：招商银行卡 5000，支付宝 1200，微信 800；花呗欠 420。平时没说怎么付的就算微信。
```

## 2 日常使用

每次新开对话时先发送下列第一句，其后写明要登记的账目：

```text
帮我记账，账本在云电脑的 ~/AI记账/ledger，按里面的 AGENTS.md 来。
今天：午饭 18 微信，打车 32 花呗。
```

- 同一对话内继续记账时不必重复第一句，直接说明即可，例如「晚饭 45 支付宝」。
- 不必每日记账；隔几日一并说明时，写清各笔的发生日期。
- 建议将第一句保存到手机备忘录或输入法常用语。
- 记账、更正、查询的表述方式见[使用指南](GUIDE.md)。

## 3 AI 的固定回报

| 时机 | AI 的回报 | 用户的处理 |
|---|---|---|
| 每次开始时 | 「账本里最后一笔是 10 月 3 日买菜 35 元」 | 与记忆不符时告知 AI |
| 每日第一次入账后 | 「今天的备份已存到云盘」；同日此后不再重复备份 | 需要立即备份时说「存一下云盘」 |
| 云盘授权失效时 | 「需要重新授权云盘」 | 选择同意，账本不受影响 |

## 4 账本的存放与恢复

| 项目 | 说明 |
|---|---|
| 日常使用的账本 | 位于豆包云电脑的个人目录。云电脑会重启，个人目录中的内容不会被清除，更换对话后仍然存在 |
| 备份 | 位于用户云盘的「AI记账」文件夹，文件名为 `ledger-backup-日期-时间.zip`，大小约几百 KB。AI 存入新备份后才删除旧备份。**不得删除该文件夹** |
| 改动记录 | 备份包含完整的改动记录：各日登记的内容、更正过的分录及其更正前的内容，均可让 AI 查询；因此只保留一份备份即可 |
| 恢复 | 云电脑中的账本丢失时，AI 从云盘最新的备份恢复，并告知恢复到哪一日；该日之后的账目需要补记，最多补记一日 |
| 保护 | 账本有错误时不生成备份，不会以损坏的账本覆盖完好的备份 |
| 迁移 | 更换 AI 工具或改在电脑上使用时，让豆包「存一下云盘」，将最新的压缩包带到新环境解压即可 |

## 5 升级

发送：

```text
帮我升级记账项目，账本数据不要动。升级完告诉我升到了哪个版本、最后一笔是什么。
```

## 6 从旧做法迁移

原先采用「每次从云盘取压缩包」做法的用户，发送下列内容，由豆包将账本迁移到固定位置，此后按第 2 节使用：

```text
记账项目换了做法，请帮我搬一次家，账本数据不能动：
1. 从我云盘「AI记账」文件夹取最新的 ledger-backup 压缩包，解压到 ~/AI记账/，得到 ~/AI记账/ledger。
2. 下载新版项目：https://github.com/Xbang0222/beancount-ai-ledger/archive/refs/heads/main.zip
   用新版覆盖账本里的 scripts、tests、docs 三个文件夹和 AGENTS.md、requirements.txt、requirements-dev.txt、pyproject.toml。
   其他的不要动，特别是 personal 文件夹、rules 文件夹（旧版是 CATEGORIES.md 等规则文件）、ledger.toml、STATE.md。
3. 重读新的 AGENTS.md 和 docs/AI-SETUP.md「没有远程仓库时」一节，按其中的规定自检、提交。
4. 告诉我最后一笔是什么，然后存一份新的备份到云盘。
以后账本就常驻 ~/AI记账/ledger，每天往云盘备份一次。
```

## 7 故障处理

豆包无响应、报告无法连接，或其回答无法确认时，追加一句「请实际检查后回答，不要猜」。豆包将区分说明哪些结论经过检查、哪些出于推断。
